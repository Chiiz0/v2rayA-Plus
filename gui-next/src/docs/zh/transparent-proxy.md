# 透明代理

透明代理可关闭、全局代理、绕过中国大陆、使用 GFWList，或跟随规则端口。配置会在保存并应用后生效。

Linux 支持 redirect、tproxy，以及 gVisor TUN 与 system TUN。具体可用性取决于系统权限、网络设备和容器配置。系统代理模式只修改受支持桌面环境的代理设置，不等同于接管所有流量。

启用 IP 转发用于转发其他设备的流量。端口共享允许其他设备访问代理端口，请按部署网络配置使用。Tproxy 白名单可指定绕过代理的国家/IP 组与自定义 CIDR。

DNS 防污染包含关闭、仅防劫持、转发、DoH 和自定义列表。自定义列表在 DNS 设置中编辑，国内与国外服务器每行一条，使用 `服务器->出口` 语法，例如 `223.5.5.5->direct` 或 `https://dns.google/dns-query->proxy`；国外列表留空时使用国内列表查询。FakeDNS 需要启用 DNS 防污染；特殊模式 supervisor 用于监测 DNS 污染。
