# 排查问题

保存失败时先阅读服务端返回的完整错误。设置、DNS 与 RoutingA 草稿会保留，便于修改后重试。无法加载现有数据时不会允许用空白默认值覆盖数据。

连接失败时检查节点参数、内核版本和日志。导入成功不代表节点可连接。透明代理还需要对应系统权限和网络支持；先确认普通 SOCKS5/HTTP 代理能连接，再排查透明代理规则与 DNS。

DNS 异常时核对防污染模式、国内/国外服务器列表及系统 DNS。检查端口占用，不要将本地解析端口递归指向自身。

恢复备份前停止写入服务，并保留当前目录用于回退。反馈问题时附上版本、复现步骤和脱敏日志，不要发布订阅地址、密码或密钥。
