# 启动参数与数据库

启动参数由运行服务的命令行、环境变量或容器配置指定。使用所安装二进制的 `v2raya --help` 查看准确选项；更改环境变量后重新创建或重启服务以使其生效。

常用参数包括 V2RAYA_ADDRESS（管理监听地址）、V2RAYA_CONFIG（配置目录）与 V2RAYA_V2RAY_BIN（内核路径）。

本项目支持保留现有 bbolt 存储，也支持通过已验证的迁移流程使用 SQLite。升级界面不会自动切换存储后端。迁移前完整备份配置目录，按项目仓库数据库迁移说明执行，保留可恢复的原始数据。

数据库迁移、恢复与服务生命周期操作应通过部署环境执行。界面不伪装提供尚未实现的在线数据库管理接口。
