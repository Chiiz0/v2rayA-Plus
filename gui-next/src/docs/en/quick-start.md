# Quick start

v2rayA-Plus manages proxy nodes and routing through the existing backend and proxy core. Both interfaces share server-side configuration. Changing the interface does not migrate the database.

1. Sign in with your existing account, or create an account for a new installation.
2. Import server links or subscription URLs on the Nodes page, or add a server manually.
3. Connect a server and start the core. Confirm that your installed core supports the selected protocol.
4. Adjust transparent proxy, rule ports and DNS in Settings, then Save and apply.

A rejected settings request keeps your draft for correction. XHTTP advanced parameters are saved with the server; their runtime support depends on the installed Xray version.
